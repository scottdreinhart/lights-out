## ✅ Usage Patterns by Document Type

### Markdown Files (PRIMARY)

```markdown
# 📚 Documentation Title

## 🏗️ Architecture Section

## 🎮 Games Section

## ✅ Status Section

## ✅ Implementation Section
```

### Status/Progress Indicators

```
✅ Complete        → Used for finished tasks, passing checks
⏳ In Progress     → Active work, tasks being done
❌ Not Implemented → Missing features, failed checks
⚠️ Warning         → Cautions, important notes
```

### File/Directory Annotations

```
## 📁 Directory Structure
- 📄 index.ts (barrel export)
- 📁 components/ (contains UI elements)
- 🎮 games/ (game implementations)
```

### Game Documentation

```
🎮 Game Name
├─ 🎲 Dice-based
├─ 🎴 Card-based
├─ ✅ Strategy
└─ ⭐ Action/Arcade
```

## 📚 Emoji Implementation Checklist

### For New Documentation Files

- [ ] Use ⭐ for "start here" recommendations
- [ ] Use ✅ for completed items
- [ ] Use ⏳ for in-progress items
- [ ] Use ❌ for not-implemented items
- [ ] Use 🎮 for game-related content
- [ ] Use 📚 for documentation sections
- [ ] Use 🏗️ for architecture content
- [ ] Use 🛠️ for build/config content

### Consistency Rules

- One emoji per major section header
- Consistent emoji for same concept across documents
- Emojis in tables for easy scanning
- Status indicators always use the same emoji
